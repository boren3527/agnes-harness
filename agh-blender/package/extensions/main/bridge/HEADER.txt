本目录（extensions/main/bridge/）下的全部 Python 脚本按 GPL-3.0-or-later 分发。

原因：这些脚本在 Blender 内运行并调用 Blender 的 Python API（bpy）。
Blender 官方许可页（https://www.blender.org/about/license/）说明：

  "Blender's Python API is an integral part of the software, used to define the user
   interface or develop tools for example. The GNU GPL license therefore requires that
   such scripts (if published) are being shared under a GPL compliant license."

GPL-3.0 全文见包根目录的 LICENSE-GPL。
本文件的机器可读副本位于包根目录的 NOTICE；包级 SPDX 标识是 Apache-2.0，
只覆盖本目录之外的部分。
